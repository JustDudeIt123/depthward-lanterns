# Assets

Project icon: custom geometric artwork built by tools/prepare_curseforge_assets.py.
Lantern geometry, block and item textures, effect icons, and darkness sound are custom resources built by that script. The sound is synthesized from deterministic noise and oscillators; no recording is sampled. The item/generated parent is a Minecraft engine template; no Minecraft texture is bundled. Former Hardcore Torches models and texture, Minecraft texture references for these items, and the supplied whisper excerpt have been replaced.
