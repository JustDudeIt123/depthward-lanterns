# DepthWard Oil Lanterns 1.3.3

Исходники отдельного мода для Minecraft 1.20.1 / Forge / Java 17. Автор: justthekingg.

Фонарь можно носить в руках, на поясе Curios, ставить или подвешивать. Топливо сохраняется при установке/разрушении, фонарь заправляется маслом. Поддерживаются настраиваемые опасности тьмы/Нижнего мира и улучшение Infernal Lens.

Динамический свет теперь находится в Lanterns и не требует DepthWard Mod Compat. Яркий сектор 150° направлен по корпусу, остальные 210° освещены слабее (20%) с плавным переходом. Установленные фонари светят радиально. Собственный источник исключён из света модели владельца для устранения мигания при движении.

Радиусы настраиваются в serverconfig. Дальность 16 блоков — настройка сборки DepthWard (heldRadius=12 × 4/3), а не стандарт отдельного мода: текущий default/migration задаёт базовый радиус 19. Серверные параметры синхронизируются клиенту.

## Зависимости и сборка

Curios 5.14.1 или совместимая 5.x версия нужен на клиенте и сервере. RyoamicLights 0.2.3+mc1.20.1 с его зависимостями нужен клиенту. Подробнее: [BUILDING.md](BUILDING.md).

## Проверки

Световой код компилировался и reobfuscation/runtime linkage проверялись локальными инструментами. Проверены геометрия, границы изменения света и исключение собственного источника; пользователь проводил игровые Spark-замеры в DepthWard. Полная свежая Gradle-сборка не подтверждена: загрузка Gradle завершилась тайм-аутом. Минимальный standalone-запуск без Compat ещё не выполнен. Снижение нагрузки и прирост FPS не заявляются.

В репозитории нет JAR релиза, сторонних модов, миров, логов или локальных кэшей. Лицензия и происхождение ресурсов сохранены без изменений.
