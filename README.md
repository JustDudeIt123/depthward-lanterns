# DepthWard Oil Lanterns 1.2.3

Актуальный кандидат публикации: [пакет CurseForge](../release/curseforge-2026-11-10/depthward-lanterns/CURSEFORGE.md). Автор — justthekingg. Модели, текстуры, значки и звук заменены собственными; см. ASSETS.md. Исторические результаты проверок ниже относятся к указанным в них версиям.

Масляный фонарь для Minecraft **1.20.1**, Forge **47.4.4**, Java **17**.
Версии из DepthWard: Curios **5.14.1+1.20.1**, Embeddium **0.3.31+mc1.20.1**,
RyoamicLights **0.2.3+mc1.20.1**. Мод устанавливается на клиент и сервер.
RyoamicLights с его зависимостями нужен только клиенту и уже есть в сборке.

## Использование

- `depthward_lanterns:oil_lantern` — фонарь, `depthward_lanterns:oil` — масло.
- Фонарь расходует топливо в основной/второй руке, в Curios и в установленном блоке.
  В обычном инвентаре, сундуке и у выброшенного предмета расхода и света нет.
- При нуле топлива предмет сохраняется, гаснет и получает погасшую модель.
- Возьмите масло в активную руку, фонарь в другую и нажмите ПКМ.
  Если в другой руке фонаря нет, заправляется неполный фонарь в Curios.
  Для установленного фонаря нажмите по нему ПКМ с маслом.
  Одна бутылка масла полностью заправляет фонарь; возвращается стеклянная бутылочка.
  Заправка уже полного фонаря масло не расходует.
- Установите фонарь на поверхность или подвесьте к потолку. Топливо сохраняется
  при разрушении блока, повторной установке, сохранении мира и перезаходе.
  Выгруженные чанки топливо не расходуют.
- Слот Curios: **belt**. Фонарь отображается спереди на правом боку игрока;
  при ходьбе качается относительно точки крепления и следует наклону тела.
- Полоса под предметом показывает оставшееся топливо; в подсказке — только состояние.

Рецепт фонаря: 4 железных самородка крестом вокруг факела.
Рецепт масла: стеклянная бутылочка + уголь + семена пшеницы (бесформенный).
Новый фонарь полностью заправлен.

## Конфиг

Шаблон: `defaultconfigs/depthward_lanterns-server.toml`.
Настройки конкретного мира: `<мир>/serverconfig/depthward_lanterns-server.toml`.
Серверные настройки автоматически передаются клиентам.
Для существующего мира редактируйте его serverconfig при выключенном сервере.

```toml
[fuel]
    durability = 1200
    damageIntervalTicks = 20
```

`durability` — запас топлива (1…1000000).
`damageIntervalTicks` — число тиков активного использования на расход одной
единицы (1…1200000). 20 игровых тиков — 1 секунда при 20 TPS.
Время полного горения: `durability × damageIntervalTicks` тиков;
по умолчанию 24000 тиков, или 20 минут. Прочность здесь — топливо:
фонарь никогда не уничтожается от его расхода. Заправка обнуляет таймер расхода.
При уменьшении ёмкости текущий запас ограничивается новым максимумом.

## Свет

В руках и Curios используется установленный в DepthWard **RyoamicLights**.
Обычный динамический источник этого мода имеет радиус 7,75 блока:
фонарь даёт **10,075 блока** на воздухе (×1,3) и **3,875 блока** в воде (×0,5
от обычного источника на воздухе). Другие источники света не изменяются.
Учитываются оба предмета в руках и Curios всех загруженных живых существ.

Установленный фонарь даёт обычный блочный свет уровня 15. Клиентский слой
RyoamicLights увеличивает визуальную дальность до **19,5 блока** (15 × 1,3).
Под водой блочный свет — 7, визуальная дальность — **7 блоков**, половина
дальности факела уровня 14 на воздухе. При пустом топливе оба слоя отключаются.
RyoamicLights должен быть включён в настройках; его отключение отключает
динамический свет и расширенный радиус, сохраняя обычный блочный свет.

Minecraft хранит блочный свет только в диапазоне 0…15: расширение радиуса
визуальное, не увеличивает серверный уровень освещения для появления мобов
и не меняет механику роста растений. Как и обычный свет RyoamicLights,
динамический слой не рассчитывает физическое перекрытие стенами.
Проверка совместимости относится к RyoamicLights из DepthWard; произвольные
моды с названием Dynamic Lights не считаются взаимозаменяемыми API.

С версии 1.2.3 модели, текстуры и звуковые ресурсы подготовлены отдельно для DepthWard,

## Сборка и проверки

Из этой папки, Java 17; зависимости берутся из `../mods`:

```sh
./gradlew build
./gradlew -PserverOnly runGameTestServer
./gradlew runClientSmoke
```

`-PserverOnly` исключает клиентские RyoamicLights, ObsidianUI, Architectury
и Embeddium из тестового сервера. Для обычного запуска клиента: `runClient`;
выделенного сервера разработки: `-PserverOnly runServer`.

Тесты проверяют границы расхода топлива, сохранение предмета при нуле,
паузы вне рук, сохранение топлива блока, затухание/заправку, Curios и возврат
бутылочки. Клиентская проверка запускает Minecraft с Embeddium, проверяет
применение mixin радиуса и загрузку моделей, затем закрывает игру.

## Экономия топлива игрока (1.0.2)

Атрибут `depthward_lanterns:fuel_efficiency`: по умолчанию **0**, диапазон **0…80**.
Значение задаёт процент уменьшения расхода топлива для фонарей в обеих руках
и Curios. Установленные фонари расходуют топливо с обычной скоростью.
Модификаторы атрибута от экипировки учитываются, итог ограничен 80.
Дробные значения поддерживаются; дробный расход сохраняется в предмете,
включая перенос через установленный блок. Старые фонари совместимы.

```mcfunction
/attribute @s depthward_lanterns:fuel_efficiency base set 80
/attribute @s depthward_lanterns:fuel_efficiency base set 0
```

Расход = обычный расход × (1 − значение / 100).
При 80 расход составляет 20%, а длительность увеличивается в **5 раз**:
с настройками по умолчанию — со **20 до 100 минут**. При 50 — 40 минут.
Конфиг прочности и интервала расхода продолжает работать.
При обновлении замените `depthward-lanterns-1.0.0.jar` на `depthward-lanterns-1.0.2.jar`
на клиенте и сервере; одновременно оставлять обе версии нельзя.

## Управление фонарём (1.0.2)

- **Shift + ПКМ** по установленному фонарю переносит его в инвентарь без
  разрушения. Сохраняются топливо, таймер, дробный расход, имя, NBT,
  зачарования и данные предмета. При полном инвентаре фонарь остаётся на месте.
  Вода на месте waterlogged-фонаря сохраняется.
- **ПКМ маслом на курсоре по фонарю в инвентаре** полностью заправляет его.
  Расходуется одна бутылка масла и возвращается стеклянная бутылочка.
  Полный фонарь масло не расходует; имя и прочие данные сохраняются.
- **R** включает/выключает фонари в Curios; клавиша переназначается в настройках
  управления. Если надето несколько фонарей, переключаются все: если хотя бы
  один включён — все выключаются, иначе все включаются.
- Выключенный фонарь не светит и не расходует топливо; он получает погасшую
  модель. Топливо и положение на поясе сохраняются. Пустой фонарь можно включить,
  но до заправки он не светит. Заправка не меняет переключатель.
- В подсказке показывается только переключатель «включён/выключен».
  Состояние сохраняется при переносе, установке и перезаходе. Старые фонари
  по умолчанию включены. Обновляйте клиент и сервер вместе до версии 1.0.2.

## Подсказка (1.0.3)

В tooltip фонаря остаётся только строка состояния, без топлива и инструкций:
`Состояние: Включен` или `Состояние: Выключен`.
Подпись белая; включённое состояние зелёное, выключенное — красное.
Ключи `tooltip.depthward_lanterns.state`, `.enabled`, `.disabled` находятся
в `assets/depthward_lanterns/lang/ru_ru.json` и `en_us.json`; их можно
переводить и переопределять ресурс-паком. Полоса топлива под предметом сохраняется.
Обновите JAR на клиенте и сервере до версии 1.0.3.

## Исправления света и удержания (1.0.4)

- Клавиша R переключает фонари одновременно в основной руке, второй руке
  и Curios. Если хотя бы один включён, все выключаются; иначе все включаются.
- Стандартный BlockItem-источник RyoamicLights отключён только для нашего
  фонаря. Светом полностью управляет собственный источник с учётом топлива
  и выключателя; другие предметы продолжают светить как обычно.
- Расход топлива сохраняется на сервере без повторной отправки состояния
  блока клиентам. Визуальное состояние обновляется при затухании/заправке.
  Иконка HUD/pick-block использует стабильный образец; подбор и выпадение
  по-прежнему сохраняют точный остаток топлива и все данные предмета.
- На поясе убрано двойное уменьшение модели (масштаб 0.5 × FIXED 0.5).
  Теперь используется масштаб 0.625 без скрытого дополнительного множителя.
- При установленном Amendments 1.20-1.2.8 и включённой его настройке
  удержания фонарь получает стандартные анимации Amendments от первого
  и третьего лица. Рендерер учитывает переключатель и пустое топливо.
  Настройка размера в руке Amendments применяется как у ванильного фонаря.
  Регистрация не включает настенное размещение, которое теряло бы топливо
  пользовательского BlockEntity. Amendments остаётся необязательным.

Проверка клиента с Amendments: `./gradlew -PwithAmendments runClientSmoke`.
Обновите JAR на клиенте и сервере до версии 1.0.4.

## Предпросмотр инвентаря и дальность (1.0.5)

Для Obscure Tooltips 2.2 добавлена необязательная интеграция, совместимая с
Obscure Tooltips Fix 1.1.0. При изменении топлива/таймера продолжает раскрываться
тот же предпросмотр; рендер получает актуальный ItemStack и полосу топлива.
Переход на другой слот, перезагрузка стиля, переименование, изменение свойств,
переключение фонаря или полное выгорание корректно обновляют анимацию.
Данные топлива и точность серверного расхода не изменяются.

В серверном конфиге добавлены радиусы в блоках (диапазон **0…64**):

```toml
[light]
    heldRadius = 10.075
    heldUnderwaterRadius = 3.875
    placedRadius = 19.5
    placedUnderwaterRadius = 7.0
```

`heldRadius` — руки и Curios на воздухе, `heldUnderwaterRadius` — под водой.
`placedRadius` и `placedUnderwaterRadius` — установленный фонарь.
Ноль отключает свет соответствующего режима, не меняя выключатель и правила расхода топлива.
Для уменьшенного радиуса установленного фонаря снижается и обычный блочный свет;
выше 15 дальность расширяет визуальный слой RyoamicLights.
Настройки передаются клиентам при входе на сервер. После редактирования
перезапустите мир/сервер и переподключите клиентов; фонари пересчитают свет.
Шаблон — `defaultconfigs/depthward_lanterns-server.toml`; для существующего мира
редактируйте `<мир>/serverconfig/depthward_lanterns-server.toml`.
Тест с модами сборки: `./gradlew -PwithTooltips -PwithAmendments runClientSmoke`.
Обновите клиент и сервер до 1.0.5.

## Тьма, адский огонь и улучшение (1.1.0)

Работа начата с актуальной `main` DepthWard: `6c341c41b1da572ad2eef46cadccb0446618d55a`
(26 октября 2026). Версии Minecraft/Forge/Curios и клиентских интеграций сохранены.

### Адская линза

Новый предмет **Адская линза** — `depthward_lanterns:infernal_lens`.
Рецепт бесформенный: огненный порошок + аметистовый осколок + золотой слиток +
стеклянная панель. Одна линза улучшает один фонарь:

- ПКМ линзой в активной руке: фонарь в другой руке; если его там нет — в Curios.
- ПКМ линзой по установленному фонарю.
- В инвентаре — ПКМ по фонарю, держа линзу на курсоре.

Флаг `Upgraded` сохраняется в NBT вместе с топливом, именем, зачарованиями,
выключателем и всеми прежними данными. Улучшение не заправляет и не включает
фонарь. Повторное применение к улучшенному фонарю линзу не расходует.
В творческом режиме линза не расходуется. Заправка маслом, перенос, подбор,
сохранение и установка не удаляют улучшение.

У улучшенного фонаря добавляется светло-голубая (`AQUA`) строка **«Улучшен»**.
Текст переводится ключом `tooltip.depthward_lanterns.upgraded` в lang-файлах:
формулировку можно заменить ресурс-паком без изменения Java-кода.
Радиус, запас топлива и экономия от улучшения автоматически не меняются.

### Окутан тьмой

Эффект `depthward_lanterns:shrouded_in_darkness`.
Проверка идёт на сервере в позиции ног игрока. По умолчанию блочный свет
должен быть 0, а суммарный свет с учётом ночного затемнения не выше 7 —
детерминированная верхняя граница проверки темноты для обычных враждебных
мобов Minecraft 1.20.1. Поверхность днём безопасна, тёмная пещера или
неосвещённое место ночью запускают опасность.

При входе в темноту **один раз** проигрывается личный шестисекундный шёпот из записи пользователя
с плавным появлением (0,8 с) и затуханием (1,2 с); предусмотрены субтитры. Первые **200 тиков / 10 секунд**
эффекта и урона нет. Затем накладывается «Окутан тьмой». Через каждые
**40 тиков / 2 секунды** активного эффекта наносятся **1, 2, 3… HP**, до
предела **20 HP за удар**. 1 HP — половина сердца. Урон может убить игрока.

Свет снимает эффект и сбрасывает задержку и рост урона. При новом входе во тьму
снова звучит шёпот и отсчитываются 10 секунд. Динамический свет RyoamicLights
не хранится в серверной световой карте, поэтому отдельно учитываются включённые
непустые фонари этого мода в руках/Curios и их настроенные радиусы, включая
установленные фонари за пределами обычного блочного света. Динамический свет
других игроков с такими фонарями тоже учитывается. Согласованно с RyoamicLights
добавочный радиус не рассчитывает перекрытие стенами. Сам спавн мобов не меняется.

### Адский огонь

Эффект `depthward_lanterns:hellfire` появляется **в Нижнем мире**, если у самого
игрока нет **улучшенного, включённого, непустого фонаря** в основной руке,
второй руке или Curios, у которого положительный радиус света в текущей среде.
Обычный фонарь, выключенный/пустой улучшенный фонарь, фонарь в рюкзаке,
на земле или у другого игрока от адского огня не защищают.

Эффект наносит **1 HP каждые 40 тиков**, **не поджигая** игрока.
При появлении защищающего фонаря или выходе из Нижнего мира эффект и таймер
снимаются. Обычный свет мира сам по себе адский огонь не отменяет.
Условия тьмы и адского огня независимы, поэтому эффекты могут действовать вместе.

Оба эффекта автоматически управляются условиями мира и не создают урон
сами по себе от `/effect give` вне этих условий. Творческий режим и зрители
не получают эффекты/урон. После входа, смены измерения и возрождения начинается
новая проверка. Сохраняется обычная неуязвимость Minecraft при появлении игрока.
Урон обходит броню, щит и стандартную задержку между ударами, но не отменяет
события Forge или модификаторы сопротивления. Эффекты не считаются обычным
поджиганием, поэтому зелье огнестойкости не заменяет защитный фонарь.

### Настройки опасностей

В `defaultconfigs/depthward_lanterns-server.toml` (шаблон) и
`<мир>/serverconfig/depthward_lanterns-server.toml` (существующий мир):

```toml
[darkness]
    enabled = true
    maximumBlockLight = 0
    maximumSkyLight = 7
    warningTicks = 200
    damageIntervalTicks = 40
    initialDamage = 1.0
    damageIncrease = 1.0
    maximumDamage = 20.0
    whisperVolume = 0.8

[hellfire]
    enabled = true
    damageIntervalTicks = 40
    damage = 1.0
```

Данные урона задаются в HP, задержки — в игровых тиках (20 TPS).
`damageIncrease = 0` оставляет постоянный урон тьмы; `warningTicks = 0`
снимает задержку после шёпота. Обе опасности отключаются независимо через `enabled`.
Новые ключи автоматически добавляются Forge в старый конфиг, прежние настройки
топлива и света сохраняются. После настройки перезапустите мир/сервер и клиентов.

```mcfunction
/give @s depthward_lanterns:infernal_lens
/effect give @s depthward_lanterns:shrouded_in_darkness 30
/effect give @s depthward_lanterns:hellfire 30
```

Новые рецепты, звук, эффекты, повреждения и переводы зарегистрированы с
пространством имён `depthward_lanterns`. Обновите JAR и на сервере, и на клиенте
до **1.1.3**, удалив старую версию.

Проверка 1.1.0: 8 модульных тестов и 18 игровых тестов, включая реальный
урон через DamageSource, десятисекундное предупреждение, защиту в Nether,
использование линзы в инвентаре/руках/Curios/мире и реальную тёмную комнату.
Клиентская проверка с Amendments, Obscure Tooltips/Fix и Embeddium проверяет
